**2. KEY DECISION — 3rd rotation slot = Upper Body**
- Rotation is now **Abs → Posterior Chain → Upper Body.**
- Legs ruled out as redundant (Douglas bikes ~60–80 min/day + posterior chain hits hams/glutes). Upper body is the genuine gap and brings back the *skill development* Douglas was missing (pull-up / handstand-pushup as chase-able goals → directly addresses the boredom problem).
- **Pull prioritized over push** — Douglas sits ~8h/day; pushing reinforces rounded posture, pulling reverses it. Upper body = posture insurance, paralleling how core work was back insurance.
- **Full upper session, NOT a push/pull split** — the 3-way rotation already puts upper at ~1.6×/week; splitting would drop each pattern to ~1×/6 days, too infrequent. Push/pull are antagonists → efficient and balance-enforcing to pair them.
- 3-slot template: Slot 1 horizontal pull (band/table rows) + Slot 2 horizontal push (push-ups, dips) every session; Slot 3 alternates vertical pull (band lat pulldown) / vertical push (pike push-ups, band/backpack overhead press).
- **Starting WITHOUT a pull-up bar** — bodyweight + bands + furniture cover it. Bar deferred (doorframe not yet checked); would add pull-ups later if desired.
- **Band pull-aparts** added as a warmup/posture staple for upper days.

**3. Pre-workout warmups — NEW, decided to add**
- Douglas asked whether warmups matter. Conclusion: yes, worth adding now — specifically because he trains in the morning (spine stiffest/least load-tolerant per McGill) and is now adding load (hinges, push-ups). Honest caveat given: injury-prevention evidence is modest for light bodyweight work; the morning-spine + increasing-load angles are what justify it.
- Principle: **dynamic (movement) before, static (holds) after.** Douglas already stretches after (correct); pre-session should be movement, not static holds.
- ~2–4 min day-specific warmups defined (abs / posterior chain / upper body). The band pull-aparts already double as an upper-body warmup.
- This is a NEW app feature — app currently has post-workout stretching but no warmup.

**4. Upper body stretches defined**
